# 생활지수 산출 기준

`/api/conditions`의 `indices`(외출, 마스크, 환기, 빨래)를 만드는 규칙입니다. 기준값은 [`backend/src/airfit/rules/life_indices.json`](../backend/src/airfit/rules/life_indices.json)에 있고, 코드([`life_indices.py`](../backend/src/airfit/life_indices.py))는 그 값을 날씨와 대기질에 적용만 합니다. 기준을 바꿀 때는 코드 대신 JSON과 이 문서를 고칩니다.

미세먼지 등급은 에어코리아가 준 값을 그대로 쓰고, 폭염 기준은 기상청 폭염특보의 체감온도 33도를 참고했습니다. 나머지 기준값은 공식 기준이 아니라 팀이 정한 값입니다. 다르게 느끼는 기준이 있으면 이슈로 알려 주세요.

측정값(미세먼지, 기온 등)은 화면에 바꾸지 않고 그대로 보여 주고, 생활지수는 그 값을 참고해 따로 만든 안내입니다.

## 응답 모양

```json
{ "grade": 3, "label": "권장", "summary": "미세먼지가 나빠요. 보건용 마스크(KF80 이상)를 쓰세요." }
```

| 필드 | 설명 |
| --- | --- |
| `grade` | 1~4. 1이 가장 좋고 4가 가장 나쁩니다. 화면은 이 값으로 카드 색을 정합니다 |
| `label` | 등급 이름. 지수마다 다릅니다 |
| `summary` | 카드에 띄울 한 문장 |

## 정하는 순서

1. 지수마다 판단에 꼭 필요한 값(`requires`)이 하나라도 없으면 그 지수는 `null`입니다. 예를 들어 대기질 조회에 실패하면 마스크와 환기가 `null`이고, 날씨 조회에 실패하면 외출과 빨래가 `null`입니다.
2. 규칙을 위에서부터 확인해 처음 맞는 규칙의 등급과 문구를 씁니다. 규칙은 나쁜 등급부터 적혀 있어서, 여러 규칙이 맞으면 가장 나쁜 등급이 됩니다.
3. 맞는 규칙이 없으면 1등급과 기본 문구(`default`)입니다.
4. 조건에 쓰는 값이 없으면(예: 외출 지수에서 대기질 없음) 그 조건만 맞지 않는 것으로 봅니다.

## 지수별 기준

"미세먼지 등급"은 미세먼지(PM10)와 초미세먼지(PM2.5) 등급 중 나쁜 쪽입니다(1 좋음, 2 보통, 3 나쁨, 4 매우나쁨).

### 외출 (`outing`)

필요한 값: 체감온도. 등급 이름: 좋음, 보통, 주의, 자제

| 등급 | 조건 | 문구 |
| --- | --- | --- |
| 4 자제 | 미세먼지 등급 4 | 미세먼지가 매우 나빠요. 외출을 줄이세요. |
| 3 주의 | 미세먼지 등급 3 | 미세먼지가 나빠요. 밖에 오래 있지 마세요. |
| 3 주의 | 체감온도 33도 이상 | 아주 더워요. 한낮 외출은 피하세요. |
| 3 주의 | 체감온도 -10도 미만 | 매우 추워요. 따뜻하게 입고 짧게 다녀오세요. |
| 2 보통 | 앞으로 12시간 강수 확률 60% 이상, 또는 지금 비나 눈 | 비나 눈 소식이 있어요. 우산을 챙기세요. |
| 1 좋음 | 그 밖 | 산책하기 좋은 날이에요. |

### 마스크 (`mask`)

필요한 값: 미세먼지 등급. 등급 이름: 불필요, 선택, 권장, 필수

| 등급 | 조건 | 문구 |
| --- | --- | --- |
| 4 필수 | 미세먼지 등급 4 | 미세먼지가 매우 나빠요. 보건용 마스크를 꼭 쓰세요. |
| 3 권장 | 미세먼지 등급 3 | 미세먼지가 나빠요. 보건용 마스크(KF80 이상)를 쓰세요. |
| 2 선택 | 미세먼지 등급 2 | 민감군은 마스크를 챙기세요. |
| 1 불필요 | 미세먼지 등급 1 | 마스크 없이 다녀도 괜찮아요. |

### 환기 (`ventilation`)

필요한 값: 미세먼지 등급. 등급 이름: 좋음, 보통, 짧게, 자제

| 등급 | 조건 | 문구 |
| --- | --- | --- |
| 4 자제 | 미세먼지 등급 4 | 미세먼지가 매우 나빠요. 창문을 닫아 두세요. |
| 3 짧게 | 미세먼지 등급 3 | 미세먼지가 나빠요. 요리한 뒤에만 짧게 환기하세요. |
| 2 보통 | 지금 비나 눈(최근 1시간 0.1mm 이상) | 비가 와요. 비가 들이치지 않게 조금만 열어 두세요. |
| 2 보통 | 미세먼지 등급 2 | 환기해도 괜찮아요. 10분 정도만 열어 두세요. |
| 1 좋음 | 그 밖 | 10분 이상 창문을 열어 두세요. |

### 빨래 (`laundry`)

필요한 값: 습도. 등급 이름: 좋음, 보통, 실내 건조, 불가

| 등급 | 조건 | 문구 |
| --- | --- | --- |
| 4 불가 | 지금 비나 눈(최근 1시간 0.1mm 이상) | 비나 눈이 와서 밖에 널 수 없어요. |
| 3 실내 건조 | 앞으로 12시간 강수 확률 60% 이상 | 비 소식이 있어요. 실내에서 말리세요. |
| 3 실내 건조 | 습도 80% 이상 | 습해서 잘 마르지 않아요. 실내에서 말리세요. |
| 3 실내 건조 | 미세먼지 등급 3 이상 | 미세먼지가 나빠요. 실내에서 말리세요. |
| 2 보통 | 습도 60% 이상 | 조금 습해요. 바람이 잘 드는 곳에 너세요. |
| 2 보통 | 체감온도 5도 미만 | 추워서 마르는 데 오래 걸려요. |
| 1 좋음 | 그 밖 | 햇볕과 바람에 잘 말라요. |

## 규칙 파일 구조

```json
{
  "mask": {
    "requires": ["dustGrade"],
    "labels": ["불필요", "선택", "권장", "필수"],
    "default": "마스크 없이 다녀도 괜찮아요.",
    "rules": [
      { "when": [{ "metric": "dustGrade", "gte": 4 }], "grade": 4, "summary": "..." }
    ]
  }
}
```

| 필드 | 설명 |
| --- | --- |
| `requires` | 하나라도 없으면 지수를 `null`로 두는 값 |
| `labels` | 1~4등급 이름, 순서대로 4개 |
| `default` | 맞는 규칙이 없을 때(1등급) 문구 |
| `rules` | 나쁜 등급부터 적습니다. `grade`는 2~4 |
| `rules[].when` | 조건 목록. 모두 맞아야 합니다. 형식은 옷차림 규칙과 같습니다([`outfit-rules.md`](outfit-rules.md)의 "규칙 파일 구조") |

조건에 쓸 수 있는 값(`metric`):

| 값 | 뜻 |
| --- | --- |
| `feelsLike` | 체감온도. 없으면 기온 |
| `humidity` | 습도(%) |
| `precipitation` | 최근 1시간 강수량(mm, 비와 눈 합산) |
| `dailyRange` | 일교차(오늘 최고 - 최저) |
| `rainChance` | 앞으로 12시간 예보의 최대 강수 확률(%). 지금 비나 눈이 오면 100 |
| `dustGrade` | 미세먼지와 초미세먼지 등급 중 나쁜 쪽 |
| `windSpeed` | 풍속(m/s) |

`backend/tests/test_life_indices.py`가 지수 이름, 등급 순서, 조건 형식을 검사하므로, 규칙을 고친 뒤 `pytest`로 확인해 주세요. 기여 절차는 [CONTRIBUTING.md](../CONTRIBUTING.md)의 "규칙(JSON) 기여"를 따릅니다.
